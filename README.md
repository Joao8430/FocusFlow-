# 🍅 FocusFlow

Um timer Pomodoro simples, moderno e responsivo desenvolvido com **HTML**, **CSS** e **JavaScript Vanilla**.

O FocusFlow ajuda você a manter o foco durante sessões de estudo ou trabalho utilizando a técnica Pomodoro: períodos concentrados de trabalho seguidos por pausas programadas.

## ✨ Funcionalidades 

* ⏱️ Cronômetro de 25 minutos
* ▶️ Iniciar contagem regressiva
* ⏸️ Pausar o cronômetro
* 🔄 Resetar para o tempo inicial
* 🔔 Alerta ao finalizar a sessão
* 🎨 Interface moderna com tema escuro
* 📱 Layout simples e responsivo

## 📖 Como Funciona

O cronômetro inicia com **25 minutos (1500 segundos)**.

* **Iniciar** → começa a contagem regressiva.
* **Pausar** → interrompe temporariamente o cronômetro.
* **Resetar** → retorna o tempo para 25 minutos.
* Ao chegar em **00:00**, uma mensagem informa que a sessão foi concluída.

## 🎯 Técnica Pomodoro

A técnica Pomodoro tradicional segue o ciclo:

1. Trabalhe por 25 minutos.
2. Faça uma pausa curta de 5 minutos.
3. Após quatro ciclos, faça uma pausa longa de 15–30 minutos.
